# Code of conduct

AudioNet follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming; assume good faith; focus on what is
best for the people who use AudioNet, including people who use screen
readers and other assistive technology; and never harass, insult or
exclude anyone.

Accessibility is part of how we treat each other here: write issues,
reviews and documentation as plain text that a screen reader reads well,
and describe images and recordings in words.

To report unacceptable behavior, contact the maintainers privately through
GitHub (for example a private security advisory at
https://github.com/mad-gamer26/AudioNet/security/advisories/new, which only maintainers can read). Reports
are handled confidentially. Maintainers may remove comments, code or
issues that break this code, and may ban people who break it repeatedly.
